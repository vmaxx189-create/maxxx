# Download Easy / DownloadersFree

A responsive cinematic static website. No login, database, build step, or API keys.

## Run
Open `index.html` in a browser or serve the directory with `python -m http.server 8000`.

## Implemented
- Cinematic responsive landing page and entrance/scroll animations
- Six tool selection modes, URL input and validation
- YouTube video/Shorts thumbnail previews and links to available image resolutions
- Accessible FAQ and responsive tool cards

## Backend integration needed
Video/Shorts MP4, MP3 conversion, channel avatar, and channel banner extraction are **not implemented** in this static-only starter. They require a separately deployed backend/provider and compliance with platform terms. The UI explicitly reports this rather than simulating a completed download. Only save material you own or are permitted to download.
